## 2. 本轮修复

### 找回密码请求缺少审计

原 `CreateResetToken()` 查询用户并写入 `action_tokens`，但没有记录“用户请求找回密码”这一安全事件。

修复后：

- 在单一数据库事务中查询 active 用户；
- 写入 `reset_password` 操作令牌摘要；
- 写入 `auth.password_reset_requested` 成功审计；
- 任一步失败时事务整体回滚；
- 对外 HTTP 响应仍使用通用文本，不暴露邮箱是否存在。

真实 PostgreSQL 集成测试确认该审计记录数量为 `1`。

## 3. 扩展认证边界验收

### 未验证账号拒绝登录

注册完成但访问邮箱验证链接前，使用正确邮箱和密码登录：

- HTTP 返回 `401 Unauthorized`；
- 不创建可用会话；
- 记录一次失败登录审计。

### 邮箱验证令牌不可重放

同一验证 URL：

- 第一次访问成功，用户状态变为 `active`；
- 第二次访问返回 `400 Bad Request`；
- consumed token 不能再次改变用户状态。

### 密码重置令牌不可重放

同一重置 token：

- 第一次提交成功并更新密码；
- 第二次提交返回 `400 Bad Request`；
- token 的 `consumed_at` 条件阻止重复使用。

### 撤销会话后的 HTTP 访问

密码重置前保存已登录会话 Cookie，重置完成后：

- 数据库中对应 session 的 `revoked_at` 已写入；
- 继续携带旧 Cookie 请求用户中心，HTTP 返回重定向到登录页；
- 旧密码登录失败，新密码登录成功。

## 4. 本地 SMTP 适配器测试

新增 `mailer_test.go`，在 `127.0.0.1` 随机端口启动单次本地假 SMTP 服务器，验证 `SMTPMailer` 完成：

- SMTP 建连；
- HELO/EHLO；
- MAIL FROM；
- RCPT TO；
- DATA；
- 邮件头和正文传输；
- QUIT。

测试断言收到的消息包含：

- From；
- To；
- Subject；
- 正文。

该测试没有连接真实 SMTP，也没有验证 SMTP AUTH、STARTTLS、证书、退信、重试或真实送达率，因此不能替代真实发信服务验收。
