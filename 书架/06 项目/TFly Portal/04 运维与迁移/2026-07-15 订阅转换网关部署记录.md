# 2026-07-15 订阅转换网关部署记录

> [!summary] 今日结果
> 已完成 Go订阅转换网关、自定义订阅主题、Nginx HTTPS入口和公开DNS的部署验证。旧的3x-ui通用订阅保持不变，Clash/Mihomo用户可使用独立转换地址获取节点、策略组和规则。

## 架构

```text
用户或 Clash/Mihomo
  → HTTPS订阅子域名
  → Nginx :443
  → 127.0.0.1:18080
  → Go订阅转换网关
  → 3x-ui原生 Clash YAML
```

## 今日增加的重点

### Go订阅转换网关

- 使用Go实现，无Docker和服务器运行时依赖。
- 通过正式YAML解析器保留 Shadowsocks、Hysteria2 等节点的扩展字段。
- 自动生成策略组和分流规则。
- 转发 `Subscription-Userinfo` 等订阅流量响应头。
- 限制上游URL模板、订阅ID格式、并发数、响应体大小和请求超时。
- 仅监听 `127.0.0.1:18080`，不直接暴露公网。
- systemd限制内存、CPU和任务数，适合当前小内存服务器。

### 自定义订阅主题

- 展示状态、已用流量、剩余流量、有效期和可用线路。
- 保留3x-ui原生通用订阅，避免影响已有用户。
- Clash/Mihomo复制和导入入口改为转换后的独立订阅地址。
- 用户订阅ID由3x-ui模板变量自动注入，不需要管理员逐个拼接。
- 导入弹窗允许用户选择 Clash Party、Clash Verge 或手动复制。

### HTTPS入口

- 3x-ui本身不依赖Nginx，因此原服务器没有443反向代理监听是正常情况。
- 安装Nginx后，只代理转换订阅路径到本机Go网关。
- 使用Certbot签发公共可信证书并配置自动续期。
- HTTPS证书域名匹配和Nginx 443监听已验证。
- Cloudflare建议使用橙云和 `Full (strict)`；签发证书时可先使用灰云。

## 关键配置原则

网关的上游模板必须指向3x-ui原生 Clash 地址，并将真实订阅ID替换为：

```text
{token}
```

转换后的公开地址仅用于交付客户端，不能反过来填入上游模板，否则会形成自请求循环。

推荐环境变量结构：

```ini
LISTEN_ADDRESS=127.0.0.1:18080
UPSTREAM_TEMPLATE=https://面板域名:面板端口/clash/{token}
CACHE_TTL=300
MAX_SOURCE_BYTES=2097152
UPSTREAM_TIMEOUT=10
VERIFY_UPSTREAM_TLS=true
MAX_CONCURRENT=8
```

## 运维命令

```bash
systemctl status tfly-sub-gateway --no-pager
journalctl -u tfly-sub-gateway -n 100 --no-pager
curl -fsS http://127.0.0.1:18080/healthz
nginx -t
systemctl reload nginx
tail -n 50 /var/log/nginx/error.log
```

检查输出是否包含完整结构：

```bash
grep -nE '^(proxies|proxy-groups|rules):' /tmp/test.yaml
```

## 安全事项

- 订阅ID等同于访问凭证，不应出现在公开截图、聊天或日志样例中。
- 已暴露的订阅ID应在部署验收后重新生成。
- Go网关继续保持回环监听，只由Nginx访问。
- Cloudflare SSL/TLS必须使用 `Full (strict)`，不要使用 `Flexible`。
- 不在知识库记录真实订阅ID、客户端密码、证书私钥或管理路径。

## 完整 Mihomo 模板升级

网关已升级为“独立完整模板 + 动态节点注入”模式：

```text
3x-ui原生订阅 → 提取proxies → 注入mihomo-template.yaml → 输出完整配置
```

模板代码位置：

```text
$env:WORKS_ROOT\3x-ui-sub\3x-ui-sub-gateway\mihomo-template.yaml
```

服务器默认安装位置：

```text
/etc/tfly-sub-gateway/mihomo-template.yaml
```

当前安全版模板包含17个策略组、21条规则和相应远程规则集。默认关闭局域网暴露，控制接口仅监听本机，TUN默认关闭，MTU为1500，并移除了企业内部域名、固定内部IP和第三方Web控制台。修改模板后只需重启网关，不需要重新编译。

v2发布包：

```text
$env:WORKS_ROOT\3x-ui-sub\releases\3x-ui-sub-gateway-go-linux-amd64-v2.zip
SHA256: D0356F66351C525B240BFD98E0192E575873F1305717A1B21B2E358A64E77C8F
```

自动选择组的健康检查地址使用 `https://cp.cloudflare.com/generate_204`，避免国内直连测试 `gstatic.com` 时将 `DIRECT` 显示为超时。
