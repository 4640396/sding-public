# MX 物料维护与车系品牌排查

## 现象

调用以下接口出现空指针：

- `/vehicle/materialInfoMaintenance/mx/insert`
- `/vehicle/materialInfoMaintenance/mx/update`

异常位于 `MxVehicleMaterialInfoMaintenanceApplicationService.validationParam()`：

```java
v.getOrganizationSeriesID().getBrand().getCode()
```

## 根因

全球仓库的 MDM `Vehicle` 转换结果只设置了物料编码和车辆信息，没有设置 `organizationSeriesID`。

全球老接口能正常维护，是因为：

- MDM 只负责校验物料编码；
- 根据当前组织和 `series` 查询本地车系；
- 品牌从本地车系取得。

## 修改

涉及文件：

- `MxVehicleMaterialInfoMaintenanceApplicationService.java`
- `MxVehicleMaterialInfoMaintenanceCommandVDO.java`

修改内容：

1. `allMaterialCode` 从 `Map<String, String>` 改为 `Set<String>`。
2. `containsKey()` 改为 `contains()`。
3. MDM 仅校验物料编码是否存在。
4. 使用 `OrganizationSeriesDomainService` 查询当前组织车系。
5. 保存时品牌使用本地车系品牌。
6. 请求字段 `brand` 改为可选。
7. 保留 MX 特有字段 `version` 和 `vehicleKey`。

品牌来源：

`请求 series → 本地车系 → 车系 brand → 组织物料 brand`

只要本地车系存在且品牌维护正确，保存的物料品牌就有值。
