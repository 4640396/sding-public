## 2026-07-09 迁移墨西哥 PurchaseInvoice 到 global 后端

### 需求结论

- 需求：把 SMMX / 墨西哥 `main/purchase-invoice` 页面的后端能力迁移到 global，前端后续可走独立的墨西哥路径。
- 最终方案：不改 global 现有 `IcInvoiceQueryController` 和 `/ic/invoice` 通用接口，新增 `MxIcInvoiceQueryController`，统一挂到 `/mx/ic/invoice`，避免影响现有全球 Purchase Invoice。
- 迁移范围：只迁移该页面实际调用的接口；页面里已注释的下拉接口不纳入本次迁移。

### 页面接口映射

| SMMX 原接口 | global 新接口 |
| --- | --- |
| `POST /ic/invoice/purchase/pagelist` | `POST /mx/ic/invoice/purchase/pagelist` |
| `POST /ic/invoice/purchase/download` | `POST /mx/ic/invoice/purchase/download` |
| `GET /ic/invoice/preview/{invoiceNo}` | `GET /mx/ic/invoice/preview/{invoiceNo}` |
| `GET /ic/invoice/download/{invoiceNo}` | `GET /mx/ic/invoice/download/{invoiceNo}` |
| `POST /ic/invoice/download/photoFiles` | `POST /mx/ic/invoice/download/photoFiles` |

### 本次实现

- 新增：`dcs-global-vehicle/dcs-service/src/main/java/com/smil/globalvehicle/invoice/userinterface/representation/MxIcInvoiceQueryController.java`
  - 参考 SMMX 的 `IcInvoiceQueryController`，类名改为 `MxIcInvoiceQueryController`。
  - `@RequestMapping` 从 `/ic/invoice` 调整为 `/mx/ic/invoice`。
  - 使用 global 已有 `MxInvoiceQueryVDO`、`MxInvoicePurchaseVO`、`InvoiceQueryService.purchasePagelist(MxInvoiceQueryVDO)`。
  - 照 SMMX 补齐列表、下载 Excel、预览、明细下载、照片文件 zip 下载 5 个接口。
- 修改：`GVInterfaceUrlAuthorityGroupEnum`
  - 在 `PURCHASE_INVOICE` 权限组中加入 5 个 `/mx/ic/invoice/**` 新接口。
  - 保留原有 `/ic/invoice/purchase/**`，不破坏旧接口。
- 修改：`InvoiceMapper.mxQueryPurchaseAll`
  - 补齐数据权限注解：`@DataScope(DataColumn(alias = "t3", name = INVOICE_BUYER))`。
  - 这里不能照抄 SMMX 的 alias；global 的 `mxQueryPurchaseAll` SQL 中 buyer 表别名是 `t3`。

### 数据库操作链路

- Controller：`MxIcInvoiceQueryController.purchasePagelist`
- Service：`InvoiceQueryService.purchasePagelist(MxInvoiceQueryVDO)`
- Mapper：`InvoiceMapper.mxQueryPurchaseAll(...)`
- SQL：`dcs-global-vehicle/dcs-service/src/main/resources/mappers/ic/InvoiceMapper.xml` 中的 `mxQueryPurchaseAll`
- SQL 逻辑：基于 `ic_invoice`，关联 seller、buyer、invoice_info，支持组织、业务发票号、时间、状态、是否上传照片、批量发票号过滤，并返回 CIPL / BL 文件地址。

### 和 SMMX 比对结论

- SMMX 的 `queryPurchaseAll` 已有数据权限；global 的 `mxQueryPurchaseAll` 原本缺少，已补齐。
- global 已经存在墨西哥专用 VO / VDO / service / mapper XML，不需要新增底层 SQL。
- `photoFiles` 下载依赖 Azure 文件绝对路径和 zip 输出；global 公共工具方法与 SMMX 不完全一致，因此在新 controller 内部保留局部 zip 方法，降低对公共工具的侵入。
