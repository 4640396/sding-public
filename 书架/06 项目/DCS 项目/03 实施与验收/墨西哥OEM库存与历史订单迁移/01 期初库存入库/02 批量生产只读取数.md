# MX OEM STOCK 按业务 VIN 批量生产只读取数

> [!important] 业务范围
> `Initial Stock Preparation - July 15 2026.xlsx` 中业务确认的 `OEM_STOCK` VIN 是唯一白名单。只为白名单 VIN 重建采购、发运和 Gate In 链路；同订单、同发票下不在白名单中的其他 VIN 一律忽略，不进入模板和 DCS。

## 一、统一业务关系

```text
一个业务库存 VIN
→ 一个有效 OEM 采购订单
→ 一条形成当前库存的有效发运记录
→ 一次 Gate In
```

有效 OEM 采购订单固定条件：

```text
sales_company_no = 5000
customer_no = 270165
source_code = 1
data_status = 4
shipper = 1
```

有效发运记录首先满足 `lm_gds_delivery_interface.e_type='S'`，并且发运明细的 `customer_order_no` 与有效 OEM 采购订单号一致。技术上的最新写入记录不是独立业务标准；只有多条成功记录的业务指纹完全相同时，才按 `im_time DESC, id DESC` 取最新同步行。

## A. 一次性候选全集导出范围

2026-07-18 已接受的生产候选查询条件为：

```sql
WHERE g.e_type = 'S'
  AND g.ship_to_party_no = '270165'
  AND g.invoice_date >= '2023-01-01'
  AND g.invoice_date < '2026-07-16'
```

- `e_type='S'` 是成功 GDS 发运硬条件。
- `ship_to_party_no='270165'` 是本次已接受的候选范围条件；原分析条件 `gi.customer_order_no LIKE 'MXASMIL%'` 不再作为现行执行条件，仅保留为历史分析线索。
- 日期范围对应当前业务库存快照的历史候选窗口，首次全量执行仍需核对边界覆盖。
- 候选查询不得直接成为导入范围；运维完整导出后，必须在本地与业务 18,449 个唯一 VIN 做交集，只有白名单 VIN 才能进入订单、发运和 Gate In 模板。
- 早期页面导出只覆盖 16,979 个业务 VIN，属于已被后续全量导出替代的排查证据。2026-07-21 新版运维全量导出为 280,277 行，已命中业务白名单全部 18,449 个唯一 VIN；本地规则筛选后，18,396 辆进入常规模板，53 辆因模板字段异常单独隔离，261,828 个非业务候选 VIN全部排除。具体证据见 [[04 生产数据比对与批次模板准备记录]]。

> [!warning] 尚未验证边界
> `ship_to_party_no='270165'` 会排除其他 Ship-to 的成功 GDS 发运。该排除是当前 accepted 决策，不是已验证的通用业务规则。若候选导出与业务白名单交集无法覆盖应迁 VIN，必须停止并重新确认范围，不得把缺失 VIN 静默剔除。

候选结果必须至少保留采购和发运模板需要的原始字段：GDS 主表、GDS 明细、`tom_trade_order`、`tom_trade_order_material`、`tom_vehicle_order`，并按 [[05 UAT客户号切换为270165决策]] 补充当前固定转换值 `DEALER SAP NO=270165`、发运 `customerNumber=270165`、`area=Others`。模板 `Price` 必须取车辆级 `tom_vehicle_order.final_price`；`tom_trade_order_material.unit_price` 只作为基础订单价格留痕。存在有效原采购发票时，必须再用 `ic_invoice_item.price` 核对车辆最终价。正式模板生成前还必须检查订单、物料、价格、描述、发票金额、必要日期、船名和航次。

### A.1 复制执行入口：候选全集与模板字段检查

下面是当前现行 SQL。首次验证保留末尾 `LIMIT 100`；字段、语法和结果检查通过后，交运维全量导出时只删除最后一行 `LIMIT 100`，不得修改其他范围条件。运维必须使用完整结果导出，不得受查询页面默认行数限制。

```sql
SELECT
    g.id AS gds_interface_id,
    g.im_time AS gds_sync_time,
    g.e_type AS gds_status,

    gi.customer_order_no AS purchase_order_no,
    DATE_FORMAT(tor.pricing_date, '%Y-%m-%d') AS price_date,
    DATE_FORMAT(tor.pricing_date, '%Y-%m-%d') AS order_date,
    '270165' AS dealer_sap_no,
    tor.delivery_destination AS delivery_short_name,
    gi.vehicle_vin AS vin,
    gi.material_no AS material_code,
    DATE_FORMAT(g.invoice_date, '%Y-%m-%d') AS purchase_invoice_date,
    g.invoice_no AS purchase_invoice_no,
    tor.incoterm_code AS incoterm_code,
    vo.final_price AS unit_price,
    tor.currency AS currency,
    tm.material_description AS material_description,
    tm.interior_description AS interior_description,
    tm.exterior_description AS exterior_description,

    gi.customer_order_no AS shipping_sales_order_no,
    gi.vehicle_vin AS shipping_vin,
    gi.engine_code AS engine_no,
    gi.material_no AS shipping_material_code,
    DATE_FORMAT(gi.offline_date, '%Y-%m-%d') AS offline_date,
    DATE_FORMAT(gi.call_car_date, '%Y-%m-%d') AS call_vehicle_date,
    gi.delivery_no AS delivery_no,
    g.invoice_no AS shipping_invoice_no,
    gi.sap_out_delivery_no AS outward_delivery_order_no,
    COALESCE(g.delivery_plan, '') AS delivery_plan,
    COALESCE(g.delivery_play_remark, '') AS delivery_plan_remark,
    COALESCE(DATE_FORMAT(g.send_time, '%Y-%m-%d'), '') AS tt_send_document_date,
    'Others' AS area,
    COALESCE(g.country, '') AS country,
    CONCAT_WS(' ', g.vessel_name, g.voyage) AS vessel_and_voyage,
    DATE_FORMAT(g.etd, '%Y-%m-%d') AS start_transport_date,
    COALESCE(g.port_of_departure, '') AS port_of_loading,
    COALESCE(g.port_of_destination, '') AS destination_port,
    COALESCE(DATE_FORMAT(g.submit_date, '%Y-%m-%d'), '') AS date_of_bill_of_loading,
    COALESCE(DATE_FORMAT(g.bl_date, '%Y-%m-%d'), '') AS date_of_bill,
    COALESCE(g.bl_no, '') AS bill_no,
    '270165' AS customer_number,
    COALESCE(g.ship_to_party_no, '') AS ship_to_party_number,
    g.invoice_amount AS invoice_amount,
    DATE_FORMAT(g.invoice_date, '%Y-%m-%d') AS shipping_invoice_date,
    COALESCE(gi.declaration_of_ch_name, '') AS customs_chinese_name,
    COALESCE(gi.declaration_of_en_name, '') AS customs_english_name,

    g.customer_no AS source_gds_customer_no,
    g.ship_to_party_no AS source_ship_to_party_no,
    tor.trade_order_no AS source_trade_order_no,
    tor.sales_company_no AS source_sales_company_no,
    tor.customer_no AS source_order_customer_no,
    tor.source_code AS source_code,
    tor.data_status AS data_status,
    tor.shipper AS shipper,
    tor.delivery_country AS delivery_country,
    vo.vehicle_order_no AS source_vehicle_order_no,
    tm.unit_price AS source_material_unit_price,
    vo.final_price AS source_vehicle_final_price,
    ia.invoice_item_price AS source_invoice_item_price,
    ia.vat_amount AS source_vat_amount,
    ia.price_including_vat AS source_price_including_vat,
    COALESCE(ia.active_invoice_item_count, 0) AS active_invoice_item_count,

    CASE
        WHEN vo.vehicle_order_no IS NULL THEN 'STOP:VEHICLE_ORDER_NOT_FOUND'
        WHEN vo.final_price IS NULL THEN 'STOP:VEHICLE_FINAL_PRICE_NULL'
        WHEN COALESCE(ia.active_invoice_item_count, 0) > 1 THEN 'STOP:MULTIPLE_ACTIVE_INVOICE_ITEMS'
        WHEN ia.invoice_item_price IS NOT NULL
         AND vo.final_price <> ia.invoice_item_price THEN 'STOP:FINAL_PRICE_INVOICE_PRICE_MISMATCH'
        ELSE 'PASS'
    END AS price_check,

    CASE
        WHEN tor.sales_company_no IS NULL
          OR tor.customer_no IS NULL
          OR tor.source_code IS NULL
          OR tor.data_status IS NULL
          OR tor.shipper IS NULL THEN 'STOP:ORDER_FIELD_NULL'
        WHEN tor.sales_company_no <> '5000' THEN 'STOP:SALES_COMPANY'
        WHEN tor.source_code <> 1 THEN 'STOP:SOURCE_CODE'
        WHEN tor.data_status <> 4 THEN 'STOP:ORDER_STATUS'
        WHEN tor.shipper <> 1 THEN 'STOP:SHIPPER'
        ELSE 'PASS'
    END AS order_scope_check,

    CASE
        WHEN gi.vehicle_vin IS NULL OR gi.vehicle_vin = '' THEN 'STOP:VIN'
        WHEN gi.customer_order_no IS NULL OR gi.customer_order_no = '' THEN 'STOP:ORDER_NO'
        WHEN tor.pricing_date IS NULL THEN 'STOP:ORDER_DATE'
        WHEN tor.delivery_destination IS NULL OR tor.delivery_destination = '' THEN 'STOP:DELIVERY_DESTINATION'
        WHEN tor.incoterm_code IS NULL OR tor.incoterm_code = '' THEN 'STOP:INCOTERM'
        WHEN tor.currency IS NULL OR tor.currency = '' THEN 'STOP:CURRENCY'
        WHEN gi.material_no IS NULL OR gi.material_no = '' THEN 'STOP:MATERIAL_CODE'
        WHEN tm.vehicle_material_code IS NULL THEN 'STOP:ORDER_MATERIAL_NOT_FOUND'
        WHEN vo.final_price IS NULL THEN 'STOP:VEHICLE_FINAL_PRICE'
        WHEN tm.material_description IS NULL OR tm.material_description = '' THEN 'STOP:MATERIAL_DESCRIPTION'
        WHEN tm.interior_description IS NULL OR tm.interior_description = '' THEN 'STOP:INTERIOR_DESCRIPTION'
        WHEN tm.exterior_description IS NULL OR tm.exterior_description = '' THEN 'STOP:EXTERIOR_DESCRIPTION'
        WHEN g.invoice_no IS NULL OR g.invoice_no = '' THEN 'STOP:INVOICE_NO'
		WHEN g.invoice_amount IS NULL THEN 'STOP:INVOICE_AMOUNT'
        WHEN g.invoice_date IS NULL THEN 'STOP:INVOICE_DATE'
        WHEN gi.offline_date IS NULL THEN 'STOP:OFFLINE_DATE'
        WHEN gi.call_car_date IS NULL THEN 'STOP:CALL_CAR_DATE'
        WHEN gi.delivery_no IS NULL OR gi.delivery_no = '' THEN 'STOP:DELIVERY_NO'
        WHEN gi.sap_out_delivery_no IS NULL OR gi.sap_out_delivery_no = '' THEN 'STOP:OUTWARD_DELIVERY_NO'
        WHEN g.etd IS NULL THEN 'STOP:ETD'
        WHEN g.vessel_name IS NULL OR g.vessel_name = '' THEN 'STOP:VESSEL_NAME'
        WHEN g.voyage IS NULL OR g.voyage = '' THEN 'STOP:VOYAGE'
        ELSE 'PASS'
    END AS template_check,

    CONCAT_WS(',',
        CASE WHEN g.send_time IS NULL THEN 'TT_SEND_DOCUMENT_DATE' END,
        CASE WHEN g.submit_date IS NULL THEN 'DATE_OF_BILL_OF_LOADING' END,
        CASE WHEN g.bl_date IS NULL THEN 'DATE_OF_BILL' END,
        CASE WHEN g.bl_no IS NULL OR g.bl_no = '' THEN 'BILL_NO' END,
        CASE WHEN g.ship_to_party_no IS NULL OR g.ship_to_party_no = '' THEN 'SHIP_TO_PARTY' END,
        CASE WHEN gi.declaration_of_ch_name IS NULL OR gi.declaration_of_ch_name = '' THEN 'CUSTOMS_CHINESE_NAME' END,
        CASE WHEN gi.declaration_of_en_name IS NULL OR gi.declaration_of_en_name = '' THEN 'CUSTOMS_ENGLISH_NAME' END
    ) AS optional_field_warning

FROM lm_gds_delivery_interface g
JOIN lm_gds_delivery_interface_item gi
  ON gi.lm_delivery_interface_id = g.id
JOIN tom_trade_order tor
  ON tor.trade_order_no = gi.customer_order_no
 AND tor.customer_no = '270165'
LEFT JOIN tom_trade_order_material tm
  ON tm.trade_order_no = tor.trade_order_no
 AND tm.vehicle_material_code = gi.material_no
LEFT JOIN tom_vehicle_order vo
  ON vo.trade_order_no = tor.trade_order_no
 AND vo.vin = gi.vehicle_vin
 AND vo.vehicle_material_code = gi.material_no
LEFT JOIN (
    SELECT
        ii.vehicle_order_no,
        COUNT(*) AS active_invoice_item_count,
        MAX(ii.price) AS invoice_item_price,
        MAX(ii.vat_amount) AS vat_amount,
        MAX(ii.price_including_vat) AS price_including_vat
    FROM ic_invoice_item ii
    JOIN ic_invoice inv
      ON inv.invoice_no = ii.invoice_no
     AND inv.invoice_status = 1
    GROUP BY ii.vehicle_order_no
) ia
  ON ia.vehicle_order_no = vo.vehicle_order_no
WHERE g.e_type = 'S'
ORDER BY
    gi.vehicle_vin,
    gi.customer_order_no,
    g.im_time DESC,
    g.id DESC;
```

验证时先检查 `order_scope_check`、`price_check`、`template_check` 和 `optional_field_warning`。三项硬检查必须全部为 `PASS`。`active_invoice_item_count=0` 表示该车没有有效原采购发票，可继续按车辆最终价迁移；大于 1 必须停止。存在一条有效原采购发票时，`source_vehicle_final_price` 必须等于 `source_invoice_item_price`。本 SQL 输出的是候选全集和模板源字段，不是最终导入文件；全量结果仍须与业务 18,449 VIN 白名单做交集、按有效发运业务指纹去重，再拆分为订单 Sheet 和发运 Sheet。

每次把 `<BUSINESS_VIN_LIST>` 替换为当前业务批次 VIN，例如：

```text
'VIN_A','VIN_B','VIN_C'
```

替换后搜索字符 `<`，结果必须为 0。生产只读平台先从 1 个 VIN 验证，再扩到 20 个；不得直接提交 18,449 个 VIN 的单条 `IN` 查询。

## 0. 有效 OEM 采购订单唯一性检查

每个输入 VIN 必须返回一行且 `order_check=PASS`。SQL 返回 VIN 数少于输入唯一 VIN 数时，缺失 VIN 判定为 `STOP:VIN_OR_ORDER_NOT_FOUND`。

```sql
SELECT
    vo.vin,
    COUNT(DISTINCT tor.trade_order_no) AS valid_oem_order_count,
    GROUP_CONCAT(DISTINCT tor.trade_order_no ORDER BY tor.trade_order_no SEPARATOR ',') AS valid_oem_order_nos,
    CASE
      WHEN COUNT(DISTINCT tor.trade_order_no) = 1 THEN 'PASS'
      WHEN COUNT(DISTINCT tor.trade_order_no) = 0 THEN 'STOP:OEM_ORDER_NOT_FOUND'
      ELSE 'STOP:MULTIPLE_OEM_ORDERS'
    END AS order_check
FROM tom_vehicle_order vo
JOIN tom_trade_order tor ON tor.trade_order_no = vo.trade_order_no
WHERE vo.vin IN (<BUSINESS_VIN_LIST>)
  AND tor.sales_company_no = '5000'
  AND tor.customer_no = '270165'
  AND tor.source_code = 1
  AND tor.data_status = 4
  AND tor.shipper = 1
GROUP BY vo.vin
ORDER BY vo.vin;
```

一个 VIN 命中多个有效 OEM 采购订单时停止，不得全部导入，也不得自行按时间选一个。

## 1. 有效发运记录唯一性检查

业务指纹由订单、发票、发运单、外向交货单、送达方、目的港、预计起运日期和开票日期组成。`successful_sync_row_count>1` 但 `shipping_fingerprint_count=1` 表示同一业务发运被重复同步，可在导出时取最新成功同步行；指纹超过 1 表示业务内容冲突，必须停止该 VIN。

```sql
SELECT
    vo.vin,
    tor.trade_order_no AS valid_oem_order_no,
    COUNT(DISTINCT g.id) AS successful_sync_row_count,
    COUNT(DISTINCT CONCAT_WS('|',
      tor.trade_order_no,
      IFNULL(g.invoice_no, ''),
      IFNULL(gi.delivery_no, ''),
      IFNULL(gi.sap_out_delivery_no, ''),
      IFNULL(g.ship_to_party_no, ''),
      IFNULL(g.port_of_destination, ''),
      IFNULL(DATE_FORMAT(g.etd, '%Y-%m-%d'), ''),
      IFNULL(DATE_FORMAT(g.invoice_date, '%Y-%m-%d'), '')
    )) AS shipping_fingerprint_count,
    GROUP_CONCAT(DISTINCT g.invoice_no ORDER BY g.invoice_no SEPARATOR ',') AS invoice_nos,
    GROUP_CONCAT(DISTINCT gi.delivery_no ORDER BY gi.delivery_no SEPARATOR ',') AS delivery_nos,
    CASE
      WHEN COUNT(DISTINCT g.id) = 0 THEN 'STOP:SUCCESS_SHIPPING_NOT_FOUND'
      WHEN COUNT(DISTINCT CONCAT_WS('|',
        tor.trade_order_no,
        IFNULL(g.invoice_no, ''),
        IFNULL(gi.delivery_no, ''),
        IFNULL(gi.sap_out_delivery_no, ''),
        IFNULL(g.ship_to_party_no, ''),
        IFNULL(g.port_of_destination, ''),
        IFNULL(DATE_FORMAT(g.etd, '%Y-%m-%d'), ''),
        IFNULL(DATE_FORMAT(g.invoice_date, '%Y-%m-%d'), '')
      )) <> 1 THEN 'STOP:MULTIPLE_EFFECTIVE_SHIPPING'
      WHEN MAX(g.invoice_no IS NULL OR g.invoice_no = '') = 1 THEN 'STOP:INVOICE_NO'
      WHEN MAX(gi.offline_date IS NULL OR gi.call_car_date IS NULL
            OR g.etd IS NULL OR g.invoice_date IS NULL) = 1 THEN 'STOP:REQUIRED_SHIPPING_DATE'
      ELSE 'PASS'
    END AS shipping_check
FROM tom_vehicle_order vo
JOIN tom_trade_order tor ON tor.trade_order_no = vo.trade_order_no
LEFT JOIN lm_gds_delivery_interface_item gi
  ON gi.vehicle_vin = vo.vin
 AND gi.customer_order_no = tor.trade_order_no
LEFT JOIN lm_gds_delivery_interface g
  ON g.id = gi.lm_delivery_interface_id
 AND g.e_type = 'S'
WHERE vo.vin IN (<BUSINESS_VIN_LIST>)
  AND tor.sales_company_no = '5000'
  AND tor.customer_no = '270165'
  AND tor.source_code = 1
  AND tor.data_status = 4
  AND tor.shipper = 1
GROUP BY vo.vin, tor.trade_order_no
ORDER BY vo.vin;
```

若返回 `STOP:SUCCESS_SHIPPING_NOT_FOUND`，先检查该 VIN 是否存在成功发运但 `customer_order_no` 为空或不等于 OEM 订单号；这属于源数据关联异常，不得退回“直接取最新记录”。

## 2. 导出订单 Sheet

只导出当前业务 VIN。一个订单下多个业务 VIN 会输出多行，转换程序按订单和物料汇总数量；同订单其他非业务 VIN 不会进入模板。

```sql
SELECT
    tor.trade_order_no                         AS `客户订单号`,
    DATE_FORMAT(tor.pricing_date, '%Y-%m-%d') AS `销售定价日期`,
    DATE_FORMAT(tor.pricing_date, '%Y-%m-%d') AS `下单日期`,
    '270165'                                   AS `DEALER SAP NO`,
    tor.delivery_destination                   AS `DELIVERY SHORT NAME`,
    vo.vehicle_material_code                   AS `Material Code`,
    DATE_FORMAT(g.invoice_date, '%Y-%m-%d')    AS `开票日期`,
    g.invoice_no                               AS `INVOICE NO`,
    tor.incoterm_code                          AS `Incoterm`,
    vo.final_price                             AS `Price`,
    tor.currency                               AS `Currency`,
    tm.material_description                    AS `Material Description`,
    tm.interior_description                    AS `Interior Description`,
    tm.exterior_description                    AS `Exterior Description`
FROM tom_vehicle_order vo
JOIN tom_trade_order tor ON tor.trade_order_no = vo.trade_order_no
JOIN tom_trade_order_material tm
  ON tm.trade_order_no = tor.trade_order_no
 AND tm.vehicle_material_code = vo.vehicle_material_code
JOIN lm_gds_delivery_interface g
  ON g.id = (
      SELECT g2.id
      FROM lm_gds_delivery_interface_item gi2
      JOIN lm_gds_delivery_interface g2 ON g2.id = gi2.lm_delivery_interface_id
      WHERE gi2.vehicle_vin = vo.vin
        AND gi2.customer_order_no = tor.trade_order_no
        AND g2.e_type = 'S'
      ORDER BY g2.im_time DESC, g2.id DESC
      LIMIT 1
  )
WHERE vo.vin IN (<BUSINESS_VIN_LIST>)
  AND tor.sales_company_no = '5000'
  AND tor.customer_no = '270165'
  AND tor.source_code = 1
  AND tor.data_status = 4
  AND tor.shipper = 1
ORDER BY tor.trade_order_no, vo.vin;
```

业务 Excel 的 `VEHICLEMATERIALCODE` 可以为空；模板物料必须来自生产车辆订单。模板 `Price` 使用 `vo.final_price`，不得再使用 `tm.unit_price`。生产物料为空、车辆最终价为空、有效原采购发票价格与车辆最终价不一致、找不到订单物料或业务非空物料与生产值冲突时停止。

## 3. 导出发运 Sheet

只导出业务 VIN，并使用 SQL 1 已证明业务指纹唯一的最新成功同步行。

```sql
SELECT
    tor.trade_order_no                         AS `销售订单号`,
    vo.vin                                     AS `Vehicle VIN`,
    gi.engine_code                             AS `发动机码`,
    gi.material_no                             AS `主物料号`,
    DATE_FORMAT(gi.offline_date, '%Y-%m-%d')   AS `下线日期`,
    DATE_FORMAT(gi.call_car_date, '%Y-%m-%d')  AS `CALL车日期`,
    gi.delivery_no                             AS `发运单编号`,
    g.invoice_no                               AS `议付发票号`,
    gi.sap_out_delivery_no                     AS `外向交货单号`,
    g.delivery_plan                            AS `发运计划`,
    g.delivery_play_remark                     AS `发运计划备注`,
    DATE_FORMAT(g.send_time, '%Y-%m-%d')       AS `TT寄单日期`,
    'Others'                                   AS `区域`,
    g.country                                  AS `国家`,
    CONCAT_WS(' ', g.vessel_name, g.voyage)   AS `船名航次`,
    DATE_FORMAT(g.etd, '%Y-%m-%d')             AS `预计起运日期`,
    g.port_of_departure                        AS `起运港`,
    g.port_of_destination                      AS `目的港`,
    DATE_FORMAT(g.submit_date, '%Y-%m-%d')     AS `收提单日期`,
    DATE_FORMAT(g.bl_date, '%Y-%m-%d')         AS `提单日期`,
    g.bl_no                                    AS `提单号`,
    '270165'                                   AS `客户编号`,
    g.ship_to_party_no                         AS `送达方编号`,
    g.invoice_amount                           AS `发票金额`,
    DATE_FORMAT(g.invoice_date, '%Y-%m-%d')    AS `开票日期`,
    gi.declaration_of_ch_name                  AS `报关中文名称`,
    gi.declaration_of_en_name                  AS `报关英文名称`
FROM tom_vehicle_order vo
JOIN tom_trade_order tor ON tor.trade_order_no = vo.trade_order_no
JOIN lm_gds_delivery_interface_item gi
  ON gi.vehicle_vin = vo.vin
 AND gi.customer_order_no = tor.trade_order_no
JOIN lm_gds_delivery_interface g
  ON g.id = gi.lm_delivery_interface_id
 AND g.e_type = 'S'
 AND g.id = (
      SELECT g2.id
      FROM lm_gds_delivery_interface_item gi2
      JOIN lm_gds_delivery_interface g2 ON g2.id = gi2.lm_delivery_interface_id
      WHERE gi2.vehicle_vin = vo.vin
        AND gi2.customer_order_no = tor.trade_order_no
        AND g2.e_type = 'S'
      ORDER BY g2.im_time DESC, g2.id DESC
      LIMIT 1
  )
WHERE vo.vin IN (<BUSINESS_VIN_LIST>)
  AND tor.sales_company_no = '5000'
  AND tor.customer_no = '270165'
  AND tor.source_code = 1
  AND tor.data_status = 4
  AND tor.shipper = 1
ORDER BY tor.trade_order_no, vo.vin;
```

`send_time`、`submit_date`、`bl_date` 允许为空，分别在模板中保留为空；不得人工补造。`offline_date`、`call_car_date`、`etd`、`invoice_date` 是本方案必要日期。

## 4. 批次数量与范围核对

结果每行必须 `qty_check=PASS`，所有行 `business_vin_count` 汇总必须等于当前业务批次唯一 VIN 数。

```sql
SELECT
    tor.trade_order_no AS order_no,
    vo.vehicle_material_code AS material_code,
    COUNT(DISTINCT vo.vin) AS business_vin_count,
    COUNT(DISTINCT gi.vehicle_vin) AS shipping_vin_count,
    CASE WHEN COUNT(DISTINCT vo.vin) = COUNT(DISTINCT gi.vehicle_vin)
         THEN 'PASS' ELSE 'FAIL' END AS qty_check
FROM tom_vehicle_order vo
JOIN tom_trade_order tor ON tor.trade_order_no = vo.trade_order_no
JOIN lm_gds_delivery_interface_item gi
  ON gi.vehicle_vin = vo.vin
 AND gi.customer_order_no = tor.trade_order_no
JOIN lm_gds_delivery_interface g
  ON g.id = gi.lm_delivery_interface_id
 AND g.e_type = 'S'
 AND g.id = (
      SELECT g2.id
      FROM lm_gds_delivery_interface_item gi2
      JOIN lm_gds_delivery_interface g2 ON g2.id = gi2.lm_delivery_interface_id
      WHERE gi2.vehicle_vin = vo.vin
        AND gi2.customer_order_no = tor.trade_order_no
        AND g2.e_type = 'S'
      ORDER BY g2.im_time DESC, g2.id DESC
      LIMIT 1
  )
WHERE vo.vin IN (<BUSINESS_VIN_LIST>)
  AND tor.sales_company_no = '5000'
  AND tor.customer_no = '270165'
  AND tor.source_code = 1
  AND tor.data_status = 4
  AND tor.shipper = 1
GROUP BY tor.trade_order_no, vo.vehicle_material_code
ORDER BY tor.trade_order_no, vo.vehicle_material_code;
```

## 5. Gate In 辅助核对

Gate In 模板以业务 Excel 为准；本 SQL 只显示源系统参考信息。

```sql
SELECT
    vi.vin AS `VIN`,
    vi.quality_status AS `Source Quality Status`,
    DATE_FORMAT(wivg.gate_in_date, '%Y-%m-%d') AS `Source Gate In Date`,
    wiv.warehouse_no AS `Source Warehouse No`
FROM vehicle_instance vi
LEFT JOIN warehouse_inventory_vehicle wiv
  ON wiv.vin = vi.vin AND wiv.status IN (1, 2)
LEFT JOIN warehouse_inventory_vehicle_gated_in_note wivg
  ON wivg.inventory_vehicle_no = wiv.inventory_vehicle_no
WHERE vi.vin IN (<BUSINESS_VIN_LIST>)
ORDER BY vi.vin, wivg.gate_in_date DESC, wivg.create_time DESC;
```

业务 `QUALITY=NORMAL` 映射为 Gate In `Quality=1`；业务 `QUALITY=QUALITY` 映射为 `Quality=2`。直接填写 `NORMAL` 或 `QUALITY` 会触发质量枚举错误。
