# 常用运维命令清单

## 查看进程

Linux：

```bash
ps -ef | grep dcs
ps -ef | grep global-vehicle
ps -ef | grep smmx
```

Windows 本地：

```powershell
Get-Process | Where-Object { $_.ProcessName -like '*java*' }
Get-Process | Where-Object { $_.ProcessName -like '*node*' }
```

## 查看端口

Linux：

```bash
netstat -tulnp | grep 8080
lsof -i:8080
```

Windows：

```powershell
netstat -ano | findstr 8080
```

## 查看日志

Linux 常用：

```bash
tail -f app.log
tail -n 300 app.log
grep -i "error" app.log
grep -i "exception" app.log
```

如果是 systemd 管理：

```bash
journalctl -u nginx -f
journalctl -u nginx --since "1 hour ago"
```

## nginx 检查与重载

```bash
nginx -t
systemctl reload nginx
systemctl restart nginx
systemctl status nginx
```

前端页面 404 或刷新丢路由时，重点看 `try_files` 是否包含回退到对应项目的 `index.html`：

```nginx
try_files $uri $uri/ /global-vehicle/index.html;
try_files $uri $uri/ /smmx-vehicle/index.html;
```

## Maven 常用

```powershell
mvn clean
mvn clean package -DskipTests
mvn clean test
mvn clean package -pl dcs-service -am -DskipTests
```

## Git 常用

```powershell
git status --short
git log --oneline -20
git branch --show-current
git diff --stat
git diff -- path/to/file
```

## 前端常用

```powershell
npm install
npm run start
npm run build:test-global-vehicle
npm run build:test-smmx-vehicle
npm run test
```

如果老依赖安装失败，优先确认：

- Node/npm 版本是否过新。
- 公司私服或 npm registry 是否可访问。
- `node-sass` / `sass-loader` 与当前 Node 版本是否兼容。
