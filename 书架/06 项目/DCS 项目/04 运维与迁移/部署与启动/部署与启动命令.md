# 部署与启动命令

## 后端编译

global 后端：

```powershell
cd "$env:WORKS_ROOT\dcs\dcs-global-vehicle"
mvn clean package -DskipTests
```

SMMX 后端：

```powershell
cd "$env:WORKS_ROOT\dcs\dcs-smmx-vehicle"
mvn clean package -DskipTests
```

只编译主服务模块及依赖：

```powershell
cd "$env:WORKS_ROOT\dcs\dcs-global-vehicle"
mvn clean package -pl dcs-service -am -DskipTests

cd "$env:WORKS_ROOT\dcs\dcs-smmx-vehicle"
mvn clean package -pl dcs-service -am -DskipTests
```

## 后端本地启动

global 主服务入口：

```text
$env:WORKS_ROOT\dcs\dcs-global-vehicle\dcs-service\src\main\java\com\smil\GlobalVehicleServiceApplication.java
```

SMMX 主服务入口：

```text
$env:WORKS_ROOT\dcs\dcs-smmx-vehicle\dcs-service\src\main\java\com\smil\SmmxVehicleServiceApplication.java
```

global 编号服务入口：

```text
$env:WORKS_ROOT\dcs\dcs-global-vehicle\dcs-system-number-service\src\main\java\com\smil\GlobalVehicleSystemNumberServiceApplication.java
```

IDE 启动建议：

- JDK 使用 Java 8。
- Active Profile 根据环境选择：`dev`、`sit`、`pre`、`prd`、`junit`、`jmeter`、`tests`。
- 配置文件位置：`dcs-service/src/main/resources/bootstrap-*.yml`。
- 如果需要 Apollo、本地数据库、Redis、网关等外部依赖，先确认本地网络和配置中心可访问。

Jar 启动示例：

```powershell
java -jar .\dcs-service\target\dcs-global-service-*.jar --spring.profiles.active=dev
java -jar .\dcs-service\target\dcs-smmx-veh-service-*.jar --spring.profiles.active=dev
```

> 注意：本地已有按时间戳产出的 jar，例如 global 的 `dcs-global-service-...-20260703....jar`，SMMX 的 `dcs-smmx-veh-service-0.0.1-SNAPSHOT-20260623....jar`。实际启动时优先用最新构建产物。

## 前端启动

global 前端：

```powershell
cd "$env:WORKS_ROOT\dcs\dcs-global-vehicle-client"
npm install
npm run start
# 等同于 npm run dev:global-vehicle
```

也可以指定区域：

```powershell
npm run dev:global-vehicle
npm run dev:global-vehicle-junit
npm run dev:global-vehicle-tests
npm run dev:global-vehicle-regression
```

SMMX 前端：

```powershell
cd "$env:WORKS_ROOT\dcs\dcs-smmx-vehicle-client"
npm install
npm run start
# 等同于 npm run dev:smmx-vehicle
```

也可以指定区域：

```powershell
npm run dev:smmx-vehicle
npm run dev:smmx-vehicle-junit
npm run dev:smmx-vehicle-regression
```

## nginx 发布位置

`nginx.conf` 的静态资源根目录：

```text
/app/html
```

常见前端路径：

```text
/global-vehicle/
/global-vehicle-junit/
/global-vehicle-tests/
/smmx-vehicle/
```

`/api/` 代理规则：

```nginx
location /api/ {
  rewrite ^/api/(.*)$ /$1 break;
  proxy_pass http://172.29.10.9:8080;
}
```

也就是说前端请求 `/api/xxx` 会去掉 `/api` 前缀后转发到后端网关。
