# 墨西哥业务数据迁移导入流程

## 背景

这份记录用于沉淀墨西哥业务数据迁移时的初始化导入流程，主要覆盖 seller 与 non-seller 两种模式下的采购订单、发运/入库、销售订单与发票数据处理。

原始材料来自收集箱笔记 `DCS 墨西哥迁移业务数据.md`。原文存在部分编码损坏，本页已按可识别内容整理；无法完全确认的内容放在“待确认点”中。

## 适用范围

- 项目：DCS / global vehicle / SMMX Mexico 迁移相关数据
- 业务模式：
  - seller 模式
  - non-seller 模式
- 主要数据对象：
  - 采购订单
  - shipping / ASN
  - Gate In
  - 销售订单
  - 发票

## non-seller 模式

### 流程

1. Excel 转 JSON。
2. 调用批量导入采购订单接口。
3. 执行 non-seller 开票 job。
4. job 执行完成后，相关发票应完成开票。

### 接口与模板

| 步骤           | 说明                   | 接口 / 资源                                                                                                                     |

| Excel 转 JSON | non-seller 采购订单数据转换  | `com.smil.globalvehicle.tradeorder.userinterface.ops.OpsSmzaOrderDataInitializationController#initNonSellerGdsShippingData` |
| 导入采购订单       | 批量导入采购订单             | `com.smil.globalvehicle.tradeorder.userinterface.ops.OpsSmmeOrderDataInitializationController#save`                         |

|              |                      |                                                                                                                             |

## seller 模式

seller 模式涉及采购订单、Gate In、销售订单与发票导入，整体链路比 non-seller 更长。

### 简化入库流程

原始记录中提到：seller 模式的车辆入库可走 Gate In 导入与 invoice 导入，并参考“百川老师”的模板。

1. 调用期初接口 `OpsSmzaOrderDataInitializationController#initGdsShippingData`。
2. 车辆数据按 shipping 处理。
3. 该接口中 SMIL、客户、发票相关处理已经包含在内，具体字段与接口范围待确认。
4. 再从页面执行 Gate In 操作。

### 完整导入流程

1. 采购订单 Excel 转 JSON。
2. 导入期初采购订单。
3. 页面批量执行 Gate In 导入。
4. 销售订单 Excel 转 JSON。
5. 批量导入销售订单。
6. Excel 转发票 JSON。
7. 将发票导入到销售单。

### 接口与模板

| 步骤 | 说明 | 接口 / 资源 |
| --- | --- | --- |
| 采购订单 Excel 转 JSON | seller 采购发运期初数据转换 | `com.smil.globalvehicle.tradeorder.userinterface.ops.OpsSmzaOrderDataInitializationController#initGdsShippingData` |
| 导入采购订单 | 期初采购订单导入 | `com.smil.globalvehicle.tradeorder.userinterface.ops.OpsSmpOrderDataInitializationController#save` |
| Gate In | 页面批量 Gate In 导入 | 页面操作，入口待补充 |
| 销售订单 Excel 转 JSON | 经销商采购 / 销售订单数据转换 | `com.smil.globalvehicle.tradeorder.userinterface.ops.OpsSmzaOrderDataInitializationController#initData` |
| 导入销售订单 | 销售订单批量导入 | `com.smil.globalvehicle.tradeorder.userinterface.ops.OpsSmzaOrderDataInitializationController#save` |
| 发票 Excel 转 JSON | 从销售订单模板中的发票 sheet 转换发票数据 | `com.smil.globalvehicle.tradeorder.userinterface.ops.OpsSmzaOrderDataInitializationController#initInvoiceInfo` |
| 导入发票 | 销售单导入发票 | `com.smil.globalvehicle.tradeorder.userinterface.ops.OpsOrderDataInitializationController#invoice` |
| 采购发运模板 | seller 采购发运期初数据 | `seller采购发运期初数据.xlsx` |
| 经销商采购模板 | 销售订单与发票导入模板 | `经销商采购导入模板.xlsx`，发票模板在 sheet 2 |

## 建议执行顺序

### non-seller

```text
non-seller 采购订单 Excel
  -> initNonSellerGdsShippingData 转 JSON
  -> OpsSmmeOrderDataInitializationController#save 导入采购订单
  -> 执行 non-seller 开票 job
  -> 校验发票状态与发票数据
```

### seller

```text
seller 采购发运期初 Excel
  -> initGdsShippingData 转 JSON
  -> OpsSmpOrderDataInitializationController#save 导入采购订单
  -> 页面批量 Gate In
  -> 经销商采购导入模板 sheet 1 转销售订单 JSON
  -> OpsSmzaOrderDataInitializationController#save 导入销售订单
  -> 经销商采购导入模板 sheet 2 转发票 JSON
  -> OpsOrderDataInitializationController#invoice 导入发票
  -> 校验订单、Gate In、发票状态
```

## 验证点

- 采购订单是否成功生成，且关键业务字段完整。
- shipping / ASN 数据是否能支撑后续 Gate In。
- 页面批量 Gate In 后，车辆入库状态是否正确。
- 销售订单是否成功导入，订单类型是否符合预期。
- 发票是否正确关联销售单。
- non-seller 开票 job 执行后，发票是否完成开票。
- seller 模式下，销售订单导入发票后，发票状态与页面展示是否一致。
