# 保税车与非保税车入库仓库类型校验

## 现象

Gate In 入库时，如果车辆保税属性和仓库保税类型不匹配，会出现业务异常，例如：

```text
warehouse.inventoryVehicle.gateInNonBondedWarehouse
The vehicle's bonded must be free:

warehouse.inventoryVehicle.InventoryVehicleIsBondedMustBeFree
The vehicle's bonded must be free!
```

注意：平时口头可能会说“报税车”，这里代码和业务字段实际是“保税车 / bonded”。

## 核心结论

入库 Gate In 时要保证车辆保税状态和仓库类型匹配：

- 保税车，即 `vehicle_instance.bonded = BONDED`，不能入非保税仓。
- 非保税车，即已清关/free 状态，才能入非保税仓。
- SMVN 场景下，入非保税仓还会通过 CDN 确认状态判断车辆是否已经可视为 free。

可以简单记成：

```text
保税车进保税仓。
非保税/free 车进非保税仓。
```

## 代码位置

车辆保税枚举：

```text
com.smil.globalvehicle.vehicle.domain.valueobject.Bonded
```

取值：

```java
BONDED,
FREE
```

仓库保税枚举：

```text
com.smil.globalvehicle.masterdata.domain.valueobject.WarehouseBonded
```

取值：

```java
BONDED,
NONBONDED
```

`WarehouseBonded.getEnum` 中，`FREE` 和 `NON-BONDED` 都会被解析成 `NONBONDED`。

## 普通 Gate In 校验

位置：

```text
com.smil.globalvehicle.warehouse.applicationservice.service.InventoryVehicleApplicationService.validGateInBefore
```

关键逻辑：

```java
Warehouse warehouse = warehouseService.findWarehouseBy(t.getWarehouseId());
List<VehicleInfoDto> vehicleInfoDtos = vehicleApplicationService.queryVehicleBy(new VehicleQuery(Arrays.asList(t.getVin().getVin())));

if (warehouse.getWarehouseBonded() == WarehouseBonded.NONBONDED) {
    if (Bonded.BONDED.name().equals(vinBonded)) {
        result.add(t.getVin().getVin());
    }
}
```

含义：如果目标仓库是非保税仓，而车辆是 `BONDED`，则不允许入库，抛出：

```java
throw new WarehouseBusinessException("{warehouse.inventoryVehicle.gateInNonBondedWarehouse}" + StringUtils.join(result));
```

## SMVN / Teleport Gate In 校验

普通 Gate In 还有一个 `checkIsConfirm`：

```text
com.smil.globalvehicle.warehouse.applicationservice.service.InventoryVehicleApplicationService.checkIsConfirm
```

Teleport Gate In 也有类似校验：

```text
com.smil.globalvehicle.logisticsv2.applicationservice.biz.TeleportGateInNoteApplicationService.checkIsConfirm
```

关键逻辑：

```java
Organization organizationBy = organizationService.findOrganizationBy(SalesCompanyNo.SMVN_SALES_COMPANY_NO);
if (!organizationBy.getOrganizationUUID().equals(organizationUUID)) {
    return;
}

final Warehouse warehouse = warehouseDomainService.findBy(warehouseId);
if (warehouse.getWarehouseBonded().equals(WarehouseBonded.NONBONDED)) {
    Boolean result = cdnApplicationQueryService.checkIsConfirm(organizationUUID, new VIN(vin));
    if (!result) {
        throw new InventoryVehicleAlreadyPendingOrGateInBizException("warehouse.inventoryVehicle.InventoryVehicleIsBondedMustBeFree");
    }
}
```

含义：SMVN 组织下，如果入非保税仓，需要 CDN 已确认；没有确认就认为车辆还不能作为 free 车入非保税仓。

## 排查 SQL

先查车辆保税状态：

```sql
select vin, bonded, owner_warehouse, business_owner
from vehicle_instance
where vin = 'VIN_HERE';
```

再查入库目标仓库的保税类型：

```sql
select organization_uuid, warehouse_no, name, bonded, disabled
from md_organization_warehouse
where warehouse_no = 'WAREHOUSE_NO_HERE';
```

如果是 SMVN 入非保税仓，再确认 CDN 是否已经确认。具体表结构按环境可能不同，先从 VIN 反查 CDN/DN 相关记录：

```sql
select *
from lm_customs_declaration_note
where vin = 'VIN_HERE';
```

如果表里没有 VIN 字段，则按当前环境的 CDN 明细表或 DN 关联表继续反查。

## 排查思路

1. 确认目标仓库是否非保税仓：`md_organization_warehouse.bonded` 是否为 `NONBONDED`、`NON-BONDED` 或 `FREE`。
2. 确认车辆是否仍是保税状态：`vehicle_instance.bonded` 是否为 `BONDED`。
3. 如果是 `BONDED` 车辆入非保税仓，属于业务不允许。
4. 如果车辆应该已经清关，检查车辆 `bonded` 是否已更新为 `FREE`，或 SMVN 场景下 CDN 是否已确认。
5. 如果业务要求保税车入库，应选择保税仓；如果要入非保税仓，先完成清关/CDN 确认后再操作。
