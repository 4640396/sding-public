# 后端模块与配置说明

## global 后端

路径：`$env:WORKS_ROOT\dcs\dcs-global-vehicle`

父 POM：

```text
artifactId: dcs-global-vehicle
version: S17.24.20251119.PRD
packaging: pom
```

模块：

```text
dcs-service
dcs-api
dcs-system-number-service
dcs-tpc-starter
```

主服务入口：

```text
dcs-service/src/main/java/com/smil/GlobalVehicleServiceApplication.java
```

编号服务入口：

```text
dcs-system-number-service/src/main/java/com/smil/GlobalVehicleSystemNumberServiceApplication.java
```

配置文件：

```text
dcs-service/src/main/resources/bootstrap.yml
dcs-service/src/main/resources/bootstrap-dev.yml
dcs-service/src/main/resources/bootstrap-sit.yml
dcs-service/src/main/resources/bootstrap-pre.yml
dcs-service/src/main/resources/bootstrap-prd.yml
dcs-service/src/main/resources/bootstrap-junit.yml
dcs-service/src/main/resources/bootstrap-jmeter.yml
dcs-service/src/main/resources/bootstrap-tests.yml
```

## SMMX 后端

路径：`$env:WORKS_ROOT\dcs\dcs-smmx-vehicle`

父 POM：

```text
artifactId: dcs-smmx-vehicle
version: 0.0.1-SNAPSHOT
packaging: pom
```

模块：

```text
dcs-service
dcs-api
```

`pom.xml` 中 `dcs-test` 和 `dcs-system-number-service` 当前是注释状态。

主服务入口：


## 常见业务包

两个后端的领域结构相似，常见包包括：

```text
allocation       # 配车、分配规则、分配结果
credit           # 信贷、客户信用账户、OPCV
finance          # 财务、凭证、发票相关
framework        # 框架能力、锁、job、TPC、工具类
identityauthorization
invoice          # 发票创建、查询、同步、导出
logistics        # 物流、DN、CDN、PDI 等
logisticsv2      # 新物流流程
masterdata       # 主数据
price            # 价格包、价格策略、运费、保险等
settlement       # 结算、SAP voucher
tpc              # 第三方对接
tom/tradeorder   # 订单、贸易订单、审批、月度目标
vehicle          # 车辆、车型、VIN、下线、生命周期
warehouse        # 仓库、库存、VIN 生命周期汇总
```

## 注意点

- 本项目依赖 Apollo，启动前要确认环境配置完整。
- Java 版本按 POM 使用 1.8。
- global 当前版本号是发布态命名 `S17.24.20251119.PRD`，但本地 target 里也能看到 `SS1.1.20260611-SNAPSHOT` 的构建产物，排查时注意 jar 版本来源。
- SMMX 独立仓库近期提交较少，当前更多是 global 仓库中合入 SMMX 初始化项目相关内容。
