# 价格模块说明

## 模块范围

这里沉淀 DCS 中和价格查询、Price Package、订单物料查价相关的后端排查知识，主要包括：

- 订单物料价格查询。
- Price Package 匹配逻辑。
- CIF 价格组成。
- submit 已有订单时的查价参数来源。
- 价格相关业务异常和 SQL 排查入口。

## 常见问题

- [[Material Price Not Found 排查|Material Price Not Found 排查]]

## 关键代码入口

```text
dcs-global-vehicle/dcs-service/src/main/java/com/smil/globalvehicle/tom
# 订单、销售订单、贸易订单相关 application service

dcs-global-vehicle/dcs-service/src/main/java/com/smil/globalvehicle/price
# price package、FOB、Freight、Insurance 等价格查询逻辑
```

## 关键概念

- `pricing_party`：定价方，通常来自 sellerUuid。
- `pricing_domain`：定价范围，可能是 buyer 对应的 customerNo，也可能是国家码，例如 MX。
- `price_type`：价格类型，订单类型会转换成价格类型。
- CIF：不是单独一条价格，而是 `FOB + Freight + Insurance`。
