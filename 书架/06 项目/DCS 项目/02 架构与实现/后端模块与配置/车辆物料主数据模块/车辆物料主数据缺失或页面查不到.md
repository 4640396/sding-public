# 车辆物料主数据缺失或页面查不到

## 现象

排查车辆物料、订单物料、价格物料、库存 VIN 明细或发票导出时，可能遇到这些情况：

- 页面查不到某个车辆物料。
- 物料基础信息存在，但描述、颜色、series、gear、trim、model year 等字段为空。
- 价格或订单接口提示物料信息找不到。
- 发票导出缺少物料描述、车型、颜色、重量、体积等信息。
- 不同页面同一个 material code 展示结果不一致。

## 核心结论

车辆物料不是只看一张表。很多页面和服务会同时依赖这些表：

```text
vehicle_organization_material                         # 车辆物料主表
vehicle_organization_material_localized_description   # 本地化描述、颜色码、model year、gear、trim 等
vehicle_organization_material_localized_sales_info    # 销售可用、国家维度销售信息
vehicle_organization_material_purchase_info           # 采购可用信息
vehicle_colour_definition                             # 颜色码到颜色名称的定义
```

因此只维护 `vehicle_organization_material` 通常不够。如果关联表缺数据，使用 inner join 的页面会直接查不到；使用 left join 的页面可能查得到但字段为空。

## 常见代码位置

主服务：

```text
com.smil.globalvehicle.vehicle.applicationservice.OrganizationMaterialApplicationService
```

主 mapper：

```text
mappers/vehicle/OrganizationMaterialDaoMapper.xml
mappers/vehicle/OrganizationMaterialLocalizedDescriptionDaoMapper.xml
```

常见异常：

```text
vehicle.material.OrganizationMaterialNotFound
vehicle.material.LocalizedSalesInfoNotFound
```

`findOrganizationMaterialInfo` 会按：

```text
organizationUuid + vehicleMaterialCode + countryCode
```

查物料、销售信息、本地化描述。任一关键数据缺失，都可能导致后续订单、价格、发票或展示逻辑异常。

## 页面查询为什么查不到

### 车辆物料基础页

`OrganizationMaterialDaoMapper.pagelist` 使用 inner join：

```sql
from vehicle_organization_material vom
join vehicle_organization_material_localized_description voml
  on vom.organization_uuid = voml.organization_uuid
 and vom.vehicle_material_code = voml.vehicle_material_code
 and voml.material_locale = 1
join vehicle_colour_definition evcd
  on vom.organization_uuid = evcd.organization_uuid
 and evcd.colour_type = 1
 and voml.exterior_code = evcd.colour_code
join vehicle_colour_definition ivcd
  on vom.organization_uuid = ivcd.organization_uuid
 and ivcd.colour_type = 2
 and voml.interior_code = ivcd.colour_code
```

所以如果缺这些数据，页面可能直接查不到：

- `vehicle_organization_material_localized_description` 中 `material_locale = 1` 的记录。
- 外饰颜色定义：`vehicle_colour_definition.colour_type = 1`。
- 内饰颜色定义：`vehicle_colour_definition.colour_type = 2`。

### 国家维度描述 / 本地名称

`vehicleMaterialPagelist` 和 `findLocalDescriptionBy` 查的是：

```text
material_locale = 2
locale_code = countryCode
```

如果国家维度本地化描述缺失，可能会出现国家/本地描述为空或查不到。

### 销售可用

`validSalesPagelist` 查的是：

```text
vehicle_organization_material_localized_sales_info
material_locale = 2
locale_code = countryCode
saleable
```

如果销售信息缺失，价格、订单物料选择、国家维度可售性相关逻辑可能受影响。

## 排查 SQL

把 `ORG_UUID_HERE`、`MATERIAL_CODE_HERE`、`COUNTRY_CODE_HERE` 换成实际值。

### 1. 查物料主表

```sql
select *
from vehicle_organization_material
where organization_uuid = 'ORG_UUID_HERE'
  and vehicle_material_code = 'MATERIAL_CODE_HERE';
```

### 2. 查本地化描述

```sql
select *
from vehicle_organization_material_localized_description
where organization_uuid = 'ORG_UUID_HERE'
  and vehicle_material_code = 'MATERIAL_CODE_HERE';
```

重点看：

```text
material_locale
locale_code
description
exterior_code
interior_code
model_year
gear
trim_version
version
vehicle_key
```

### 3. 查组织维度描述是否存在

```sql
select *
from vehicle_organization_material_localized_description
where organization_uuid = 'ORG_UUID_HERE'
  and vehicle_material_code = 'MATERIAL_CODE_HERE'
  and material_locale = 1;
```

### 4. 查国家维度描述是否存在

```sql
select *
from vehicle_organization_material_localized_description
where organization_uuid = 'ORG_UUID_HERE'
  and vehicle_material_code = 'MATERIAL_CODE_HERE'
  and material_locale = 2
  and locale_code = 'COUNTRY_CODE_HERE';
```

### 5. 查销售可用信息

```sql
select *
from vehicle_organization_material_localized_sales_info
where organization_uuid = 'ORG_UUID_HERE'
  and vehicle_material_code = 'MATERIAL_CODE_HERE';
```

国家维度：

```sql
select *
from vehicle_organization_material_localized_sales_info
where organization_uuid = 'ORG_UUID_HERE'
  and vehicle_material_code = 'MATERIAL_CODE_HERE'
  and material_locale = 2
  and locale_code = 'COUNTRY_CODE_HERE';
```

### 6. 查采购可用信息

```sql
select *
from vehicle_organization_material_purchase_info
where organization_uuid = 'ORG_UUID_HERE'
  and vehicle_material_code = 'MATERIAL_CODE_HERE';
```

### 7. 查颜色定义能否匹配

```sql
select *
from vehicle_colour_definition
where organization_uuid = 'ORG_UUID_HERE'
  and colour_code in ('EXTERIOR_CODE_HERE', 'INTERIOR_CODE_HERE');
```

分别确认：

```text
外饰 colour_type = 1
内饰 colour_type = 2
```

## 一条总排查 SQL

```sql
select
  vom.organization_uuid,
  vom.vehicle_material_code,
  vom.brand,
  vom.series_code,
  vomld.material_locale,
  vomld.locale_code,
  vomld.description,
  vomld.model_year,
  vomld.gear,
  vomld.trim_version,
  vomld.exterior_code,
  evcd.colour_name as exterior_name,
  vomld.interior_code,
  ivcd.colour_name as interior_name,
  vomlsi.saleable,
  vompi.purchaseable
from vehicle_organization_material vom
left join vehicle_organization_material_localized_description vomld
  on vom.organization_uuid = vomld.organization_uuid
 and vom.vehicle_material_code = vomld.vehicle_material_code
left join vehicle_colour_definition evcd
  on vom.organization_uuid = evcd.organization_uuid
 and evcd.colour_type = 1
 and vomld.exterior_code = evcd.colour_code
left join vehicle_colour_definition ivcd
  on vom.organization_uuid = ivcd.organization_uuid
 and ivcd.colour_type = 2
 and vomld.interior_code = ivcd.colour_code
left join vehicle_organization_material_localized_sales_info vomlsi
  on vom.organization_uuid = vomlsi.organization_uuid
 and vom.vehicle_material_code = vomlsi.vehicle_material_code
 and vomld.material_locale = vomlsi.material_locale
 and (vomld.locale_code = vomlsi.locale_code or (vomld.locale_code is null and vomlsi.locale_code is null))
left join vehicle_organization_material_purchase_info vompi
  on vom.organization_uuid = vompi.organization_uuid
 and vom.vehicle_material_code = vompi.vehicle_material_code
where vom.organization_uuid = 'ORG_UUID_HERE'
  and vom.vehicle_material_code = 'MATERIAL_CODE_HERE';
```

## 排查思路

1. 先确认当前业务用的是哪个组织的物料：seller、当前登录组织、business owner，还是销售合同 seller。
2. 用 `organization_uuid + vehicle_material_code` 查主表。
3. 如果主表有，再查 `material_locale = 1` 的描述和颜色定义。
4. 如果是国家维度、本地描述或销售可用，查 `material_locale = 2 + locale_code`。
5. 如果页面是 inner join 查询，任何关联表缺失都可能导致整条物料不显示。
6. 如果发票导出缺字段，除了组织物料表，还要看 MDM 物料信息是否同步到 `VehicleMaterialInfo` 相关来源。
7. 如果价格模块报 `Price Not Found`，先区分是价格没维护，还是物料主数据没有提供给价格页面/查询条件。

## 和价格模块的关系

价格模块会调用 `OrganizationMaterialApplicationService` 获取物料信息。价格页面能否选择到物料、价格包能否展示物料描述，可能依赖车辆物料主数据。

但 `Material Price Not Found` 本身通常不是“物料不存在”，而是价格条件没命中。排查时建议顺序：

1. 先查车辆物料主数据是否完整。
2. 再查 Price Package / FOB / Freight / Insurance 是否命中。
