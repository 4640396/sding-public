# 项目概览与技术栈

## 项目定位

DCS 当前工作区主要包含全球整车相关代码，分为 global 和 smmx 两条线：

- `dcs-global-vehicle`：全球整车后端，README 显示为“全球整车项目 - 南美”，当前近期提交主要集中在这里。
- `dcs-global-vehicle-client`：全球整车前端，Vue 2 项目，包含 `global-vehicle`、`global-vehicle-junit`、`global-vehicle-tests` 等构建区域。
- `dcs-smmx-vehicle`：SMMX/Mexico 后端独立仓库，README 显示为“全球整车项目 - 墨西哥”。
- `dcs-smmx-vehicle-client`：SMMX/Mexico 前端，Vue 2 项目，构建区域是 `smmx-vehicle`。
- `nginx.conf`：统一前端静态资源与 `/api/` 网关代理配置。

## 技术栈

后端：

- Java 8
- Spring Boot `2.0.7.RELEASE`
- Spring Cloud `Finchley.SR2`
- Maven 多模块工程
- MyBatis / MyBatis Plus
- Apollo Client `1.1.0`
- MySQL Connector `5.1.47`

前端：

- Vue 2.5.x
- webpack 3
- element-ui 2.15.x
- vue-router / vuex
- axios 0.18
- npm scripts 区分 area 和 env

## 后端模块

`dcs-global-vehicle`：

```text
dcs-service                 # 主服务模块，入口：com.smil.GlobalVehicleServiceApplication
dcs-api                     # API 包
dcs-system-number-service   # 编号服务，入口：com.smil.GlobalVehicleSystemNumberServiceApplication
dcs-tpc-starter             # TPC starter
dcs-test                    # 测试辅助与测试资源
document                    # SQL、需求、测试、规范等文档
historytest                 # 历史测试用例
```

`dcs-smmx-vehicle`：

```text
dcs-service                 # 主服务模块，入口：com.smil.SmmxVehicleServiceApplication
dcs-api                     # API 包
dcs-test                    # 测试辅助与测试资源
document                    # SQL、需求、测试、规范等文档
```

## 前端模块

两个前端仓库都是老 Vue CLI / webpack 体系：

```text
build/                      # webpack 构建脚本
config/                     # 构建环境配置
src/                        # 页面、路由、i18n、业务代码
static/                     # 静态资源与 config.js
test/                       # e2e 测试
package.json                # 启动、构建脚本
```
