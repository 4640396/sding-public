# 部署与启动命令

## 线上环境

```text
服务器：<SERVER_HOST>
部署目录：/opt/iot-monitor
访问地址：http://<SERVER_HOST>/
接口前缀：http://<SERVER_HOST>/api/...
```

## 首次准备服务器目录

```bash
sudo mkdir -p /opt/iot-monitor
sudo chown -R $USER:$USER /opt/iot-monitor
cd /opt/iot-monitor
```

## 上传项目

从 Windows 本地上传到服务器：

```powershell
scp -r "$env:WORKS_ROOT\iot\backend" root@<SERVER_HOST>:/opt/iot-monitor/
scp -r "$env:WORKS_ROOT\iot\frontend" root@<SERVER_HOST>:/opt/iot-monitor/
scp "$env:WORKS_ROOT\iot\docker-compose.yml" root@<SERVER_HOST>:/opt/iot-monitor/
scp "$env:WORKS_ROOT\iot\.env.example" root@<SERVER_HOST>:/opt/iot-monitor/.env
```

## 修改环境变量

```bash
ssh root@<SERVER_HOST>
cd /opt/iot-monitor
vim .env
```

需要配置但不要写进笔记的敏感项：

```env
MYSQL_ROOT_PASSWORD=强密码
MYSQL_PASSWORD=强密码
APP_EXTERNAL_TOKEN=外部平台token
APP_JWT_SECRET=至少32位随机字符串
APP_WECHAT_APP_ID=服务号appid
APP_WECHAT_APP_SECRET=服务号secret
APP_WECHAT_TEMPLATE_ID=模板消息ID
ADMIN_SEED_PASSWORD=管理员密码
```

## 启动全部服务

```bash
cd /opt/iot-monitor
docker compose up -d --build
```

## 查看容器状态

```bash
docker compose ps
```

## 查看日志

```bash
docker compose logs -f backend
docker compose logs -f frontend
docker compose logs -f mysql
```

## 更新前端

前端改动后，本地或服务器构建都会影响发布方式。

如果本地已生成新 `dist`：

```powershell
scp -r "$env:WORKS_ROOT\iot\frontend\dist" root@<SERVER_HOST>:/opt/iot-monitor/frontend/
```

然后服务器执行：

```bash
cd /opt/iot-monitor
docker compose up -d --build frontend
```

如果直接上传完整前端源码：

```bash
cd /opt/iot-monitor
docker compose up -d --build frontend
```

## 更新后端

```bash
cd /opt/iot-monitor
docker compose up -d --build backend
```

## 更新 token 或环境变量后重建后端

```bash
cd /opt/iot-monitor
docker compose up -d --force-recreate backend
docker compose logs -f backend
```

## 停止服务

```bash
docker compose down
```

不要随便执行：

```bash
docker compose down -v
```

`-v` 会删除 MySQL 数据卷，容易把线上数据清掉。
