# 常用运维命令清单

## 进入服务器

```bash
ssh root@<SERVER_HOST>
cd /opt/iot-monitor
```

## 启动/重启

```bash
docker compose up -d
```

```bash
docker compose restart backend
docker compose restart frontend
docker compose restart mysql
```

## 重建发布

```bash
docker compose up -d --build
```

只重建后端：

```bash
docker compose up -d --build backend
```

只重建前端：

```bash
docker compose up -d --build frontend
```

环境变量变更后强制重建后端：

```bash
docker compose up -d --force-recreate backend
```

## 日志排查

最近 100 行后端日志：

```bash
docker compose logs -n 100 backend
```

实时后端日志：

```bash
docker compose logs -f backend
```

查看微信/告警相关日志：

```bash
docker compose logs backend --since=2h | grep -i "wechat\|alarm"
```

查看微信回调是否进来：

```bash
docker compose logs -f backend | grep "/api/wechat/callback"
```

查看清空事件接口：

```bash
docker compose logs -n 100 backend | grep "/api/alarms/events"
```

查看同步任务：

```bash
docker compose logs -f backend | grep "Scheduled sync triggered"
```

## 前端本地命令

```powershell
cd "$env:WORKS_ROOT\iot\frontend"
npm.cmd run dev
npm.cmd run build
npm.cmd run preview
```

## 后端本地命令

```powershell
cd "$env:WORKS_ROOT\iot\backend"
mvn test
mvn package
```

## 常见判断

- 前端页面报 `Unexpected token '<'`：大概率请求接口路径漏了 `/api`，拿到了前端 `index.html`。
- 微信没收到但页面有事件：先看 `iot_alarm_event.notified`，页面事件不等于微信已送达。
- 线上前端没变化：确认是否上传了新 `dist`，并重建或刷新了 frontend 容器。
- 环境变量改了不生效：确认是否 `--force-recreate backend`。
