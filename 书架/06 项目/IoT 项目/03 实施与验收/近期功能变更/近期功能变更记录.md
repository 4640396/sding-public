# 近期功能变更记录

## 节点历史 24 小时折线图

需求：设备详情页在“节点概览”和“节点历史查询”之间增加今日、昨日两个 24 小时趋势图。

关键规则：

- 默认选中第一个节点
- 点击节点后今日/昨日图同步切换
- 每小时最多一个点
- 取该小时内最接近整点的历史值
- 空小时不补 0
- 今日未来小时为空
- tooltip 显示小时、实际采样时间、节点值、单位

相关前端组件：

```text
frontend/src/components/HourlyTrendChart.jsx
frontend/src/pages/DeviceDetailPage.jsx
frontend/src/services/deviceApi.js
```

相关接口：

```text
GET /api/devices/{sn}/nodes/{address}/hourly-trend
```

## 告警规则“所有设备”模式

需求：设备选择“所有设备”时，不显示某台设备的实时值，值字段只读，显示“节点实时值”。

规则：

- 保存规则时不保存当前值
- 保存节点、条件、阈值等配置
- 执行时对所有拥有该节点的设备分别读取实时值判断
- 同一设备同一节点同时有全局规则和具体设备规则时，具体设备规则优先
- 所有设备模式下节点去重按“节点名称 + 单位”处理

已做设计：

- 后端规则增加 `matchNodeUnit`
- 新规则按节点名称和单位匹配
- 老规则单位为空时保持兼容

## 节点和值拆列显示

需求：阈值规则中的节点显示从“节点 + 当前值”拼接改成两列：

```text
节点：空气温度（地址0）
值：21.5 °C
```

意义：规则配置更清楚，也方便“所有设备”模式下把值字段置为只读提示。

## 同步间隔调整

系统同步由 `app.scheduler.cron` 控制。

当前配置示例：

```yaml
app:
  scheduler:
    cron: "*/30 * * * * *"
```

含义：每 30 秒触发一次同步。

如果要改成 5 分钟：

```yaml
cron: "0 */5 * * * *"
```

改环境变量或配置后，需要重启/重建后端。

## 自定义确认弹窗

多个页面把浏览器原生 `window.confirm` 改成应用内确认弹窗：

- 清理历史数据
- 清空事件记录

原因：原生弹窗样式突兀，文案不清晰，也无法展示平台名、保留天数等上下文。

## 角色权限路径问题

现象：页面报 `Unexpected token '<', "<!DOCTYPE"... is not valid JSON`。

原因：前端请求路径漏了 `/api`，请求到了前端 HTML。

修复后路径：

```text
GET /api/roles
GET /api/roles/{roleCode}
PUT /api/roles/{roleCode}
GET /api/roles/me/menus
```
