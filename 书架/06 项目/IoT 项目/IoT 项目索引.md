## 当前项目关键信息

### 环境信息

- **本地与线上**：本地项目目录：`$env:WORKS_ROOT\iot` · 线上部署目录：`/opt/iot-monitor`
- **服务组成**：MySQL · Spring Boot 后端 · Nginx 托管 React 前端 · Docker Compose
- **访问入口**：对外访问：`http://<SERVER_HOST>/` · 后端接口统一走：`/api/...`

## 重要提醒

### 注意事项

- 不要把真实 token、appid、secret、数据库密码写进笔记
- 更新前端后需要重新构建并发布 `frontend/dist` 或重建 frontend 容器
- 更新后端后需要重新构建 backend 容器
- 数据库卷不要随便删除，避免执行 `docker compose down -v`
