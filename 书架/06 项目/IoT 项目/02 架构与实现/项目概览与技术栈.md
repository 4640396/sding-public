# 项目概览与技术栈

## 项目定位

IoT 监控项目用于同步外部物联网平台数据，在本地展示设备、节点、历史数据、告警规则、告警事件，并支持微信服务号通知。

## 本地目录

```text
$env:WORKS_ROOT\iot
  backend/              Spring Boot 后端
  frontend/             React + Vite 前端
  docker-compose.yml    线上容器编排
  .env.example          环境变量模板
  DEPLOY.md             部署说明
```

## 技术栈

后端：
- Java 8
- Spring Boot 2.7.18
- MyBatis Plus
- MySQL
- JWT 登录认证
- Spring Scheduler 定时同步

前端：
- React 19
- Vite 7
- React Router
- lucide-react 图标
- Nginx 托管静态文件并反向代理 `/api`

容器：
- `mysql`：MySQL 8.4
- `backend`：Spring Boot 服务，容器内端口 `8080`
- `frontend`：Nginx，宿主机端口 `80`

## 核心模块

- 设备同步：`PollingService`
- 设备查询：`DeviceController`、`DeviceQueryService`
- 告警规则/事件：`AlarmController`、`AlarmService`
- 微信通知：`WechatCallbackController`、`WechatAlarmNotifier`、`AlarmNotificationTaskService`
- 平台配置：`ExternalPlatformConfigController`、`ExternalPlatformConfigService`
- 用户/角色权限：`UserController`、`RolePermissionController`

## 关键数据库表

- `iot_device`：设备基础数据
- `iot_node`：节点基础数据
- `iot_node_history`：节点历史值
- `iot_sync_batch`：同步批次
- `iot_alarm_rule`：告警规则
- `iot_alarm_rule_state`：按设备节点维护规则状态
- `iot_alarm_event`：告警/恢复事件
- `iot_alarm_notification_task`：通知任务
- `iot_alarm_recipient`：告警联系人
- `iot_alarm_recipient_wechat_bind_task`：微信绑定任务
