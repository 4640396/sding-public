# 2026-07-16 3x-ui-sub 当前代码事实核验

> [!summary] 核验边界
> 本文只记录 2026-07-16 对本地仓库文本源码可直接复现的事实，不代表生产环境已经部署或启用这些配置。用户中心、注册、订单和支付仍属于规划，不在本文中描述为已完成功能。

## 仓库组成

排除 `graphify-out`、`dist`、`releases` 和缓存目录后，当前可读源码主要由两部分组成：

- `3x-ui-sub-gateway`：Go 订阅转换服务及其配置、测试、安装脚本和 Mihomo 模板。
- `3x-ui-sub-theme`：3x-ui 订阅展示主题及说明。

当前仓库根目录没有可用的 Git 元数据，不能从本地 `git log` 复核历史提交顺序。

## Gateway 已核验事实

- `main.go` 定义了 `config`、`cacheEntry` 和 `gateway` 三个核心结构，主要逻辑集中在单个 Go 文件中。
- `loadConfig()` 从环境变量读取监听地址、上游模板、模板文件、缓存时间、响应大小、上游超时、TLS 校验和并发上限。
- `newGateway()` 读取并解析 Mihomo YAML 模板，要求模板包含 `proxy-groups` 和 `rules`。
- `serveHTTP()` 暴露 `/healthz` 和 `/clash/<token>`；订阅 token 仅做 8 至 128 位字母、数字、下划线和连字符的格式校验。
- `convert()` 将 token 替换进 `UPSTREAM_TEMPLATE`，请求 3x-ui 上游订阅，再调用 `transform()`。
- `transform()` 从上游 YAML 提取 `proxies`，拒绝缺失名称或名称重复的节点，并将代理列表注入本地 Mihomo 模板。
- 转换结果缓存在进程内存中，缓存键是请求中的 token；缓存容量没有硬性总上限，只在条目数达到 256 时清理已过期条目。
- 网关转发 `Subscription-Userinfo`、`Profile-Update-Interval` 和 `Profile-Web-Page-Url` 三类响应头。
- 当前网关代码没有读取用户表、订单表、支付状态或权益状态，也没有账号登录、会话或支付回调处理器。

## 测试覆盖事实

`main_test.go` 当前包含两个测试：

1. `TestTransformPreservesProxiesAndAddsPolicy`：验证代理字段保留、策略组与规则数量，以及部分安全模板设置。
2. `TestTransformRejectsDuplicateNames`：验证重复代理名称被拒绝。

当前文本源码中没有用户注册、会话隔离、订阅撤销、订单幂等、支付回调或 3x-ui 管理 API 的测试。

本次未执行 Go 测试，因为当前命令环境未提供 `go` 可执行程序；上述结论是源码静态核验，不是测试运行结果。

## 主题与入口事实

- `3x-ui-sub-theme/index.html` 使用 `{{ .sId }}` 拼接 `/clash/` 订阅地址。
- 同一页面仍提供 3x-ui 原生 `{{ .subUrl }}` 的复制入口。
- `nginx-location.conf` 只给出 `/clash/` 到 `127.0.0.1:18080` 的反向代理片段。
- 当前主题文本中没有登录、注册、订单或支付流程。

## 进程约束事实

`tfly-sub-gateway.service` 使用独立系统用户运行，并配置：

- `NoNewPrivileges=true`
- `ProtectSystem=strict`
- `MemoryHigh=48M`
- `MemoryMax=64M`
- `CPUQuota=20%`

这些是仓库中的 systemd 配置事实，不证明线上服务当前采用了同一文件。

## 依赖事实

`go.mod` 中模块名为 `tfly-sub-gateway`，直接依赖只有 `gopkg.in/yaml.v3`。当前没有数据库驱动、认证、邮件或支付 SDK 依赖。
