# 2026-07-16 3x-ui-sub 用户中心第一阶段实施记录

## 2. 已实现功能

### 2.1 账号与认证

- 公开邮箱注册。
- 一次性邮箱验证链接，账号验证后才进入 active 状态。
- 密码使用 Argon2id 哈希，要求 12 至 128 个字符。
- 登录、退出和 HttpOnly 会话 Cookie。
- 连续登录失败后短时锁定账号。
- 邮件找回密码和一次性重置链接。
- 密码重置后撤销该用户现有会话。
- 验证、重置和会话令牌在数据库中仅保存 SHA-256 摘要。

### 2.2 Web 安全边界

- 表单使用 CSRF Cookie 与隐藏字段校验。
- 会话 Cookie 配置 HttpOnly、SameSite，并可由环境变量强制 Secure。
- 设置 `X-Content-Type-Options`、`X-Frame-Options`、`Referrer-Policy` 和基础 CSP。
- 按规范化客户端 IP 与邮箱组合执行内存限速，客户端临时端口不会绕过同一 IP 的计数。
- 登录失败返回通用错误；注册和找回密码返回不暴露账号是否存在的通用响应。
- 非 development 环境拒绝日志邮件器和不安全 Cookie 配置。

### 2.3 邮件边界

- development 模式提供日志邮件器，用于本地查看验证和重置链接。
- 提供 SMTP 邮件器配置入口。
- 日志邮件器仅允许在 `PORTAL_ENV=development` 使用。

真实发信域名、SMTP 服务、退信和送达率没有验证，不能把邮件能力描述为可用于生产。

### 2.4 PostgreSQL 模型

初始迁移定义以下表：

- `users`
- `sessions`
- `action_tokens`
- `xui_client_bindings`
- `audit_logs`

应用启动时读取嵌入的 SQL 并执行幂等建表语句。Portal 使用独立 `PORTAL_DATABASE_URL`，代码没有直接访问 3x-ui 数据库。

### 2.5 用户首页与 3x-ui 只读边界

- 登录用户可进入基础用户中心。
- 未绑定客户端时显示“尚未绑定 3x-ui 客户端”。
- 3x-ui 未配置或请求失败时显示“数据暂不可用”，不会把未知流量误报为零。
- 可选适配器只执行登录和 `/panel/api/inbounds/list` 读取。
- 当前代码没有创建、更新、禁用或删除 3x-ui 客户端的写操作。
- 3x-ui 配置默认留空，未显式配置时使用不可用适配器。

目标 3x-ui 版本、真实字段和认证方式尚未在隔离实例验证，因此只读适配器属于本地实现事实，不是生产兼容性结论。

## 3. 配置与运行保护

Portal 启动至少要求：

- `PORTAL_DATABASE_URL`
- `PORTAL_IP_HASH_KEY`

主要可选配置包括监听地址、公开 URL、Cookie 安全属性、会话与操作令牌有效期、邮件模式、SMTP 和 3x-ui 只读连接信息。

HTTP 服务配置了请求头、读、写、空闲超时和最大请求头限制，并支持 SIGINT/SIGTERM 优雅关闭。

- `tfly-sub-portal/cmd/portal`：可编译，无独立测试文件，覆盖率 `0.0%`。
- `go vet ./...`：通过。
- Portal 可执行文件构建：通过；验证后构建产物已清理，未作为源码提交。
- 在原 `3x-ui-sub-gateway` 执行 `go test -count=1 ./...`：通过，用于确认新增 Portal 未破坏 Gateway 现有测试。

覆盖的单元或模拟测试包括：

- Argon2id 密码正确与错误校验。
- 密码最小长度。
- 随机令牌摘要一致性。
- 限速器计数与不同键隔离。
- IPv4/IPv6 临时端口规范化。
- 必填配置与 development 安全默认值。
- 非 development 环境拒绝日志邮件器。
- 基础安全响应头与健康检查。
- 邮箱规范化。
- 模拟 3x-ui 登录、Cookie 会话、客户端状态读取和未找到结果。

- `go test -race` 未执行成功：当前 Windows 便携环境未启用 CGO，Go 返回 `-race requires cgo`。这不是竞态测试通过结论。
- 当前环境没有 `psql`、Docker 或 Podman，未在真实 PostgreSQL 实例执行迁移和注册登录集成测试。
- 未连接真实 SMTP 服务。
- 未连接真实 3x-ui 实例。
- 未进行浏览器端端到端测试、压力测试或安全渗透测试。
- 未生成生产 Nginx、systemd、数据库账号或部署配置。
