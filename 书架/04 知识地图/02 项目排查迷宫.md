## DCS 迷宫地图

### 路线 A：服务、网关、注册中心、事务

```text
请求失败
  -> 网关是否命中目标服务？
  -> Eureka 是否有实例？
  -> Seata 是否注册？
  -> 配置是否指向正确环境？
  -> 重启或修正配置后验证接口
```

### 路线 C：收车、入库、物流

```text
物流类业务异常
  -> 是客户收货确认，还是 Gate In 入库？
  -> 如果是收车：查 VIN、DN、delivery destination、当前登录组织
  -> 如果是入库：查保税/非保税、仓库类型、CDN 确认状态
  -> 用 SQL 和代码入口验证查询条件
  -> 补数据或修正业务判断后验证页面/接口
```

### 路线 D：价格、订单、Price Package

```text
价格查不到
  -> 定位订单类型和物料
  -> 查 pricing_party
  -> 查 pricing_domain
  -> 查 price_type
  -> 查 Price Package 是否生效
  -> 如果是 CIF，拆成 FOB + Freight + Insurance
  -> 验证 submit 或查询接口是否返回价格
```


## IoT 迷宫地图

### 路线 A：告警有记录但微信没收到

```text
页面有告警事件
  -> iot_alarm_event.notified 是否为 1？
  -> 是否创建 iot_alarm_notification_task？
  -> 联系人是否 enabled、openid 有效、company/park 匹配？
  -> 微信回调是否进入后端？
  -> 是否命中 30 分钟去重？
  -> 看日志确认发送成功或失败原因
```

```text

  -> 核对数据库记录
  -> 判断是数据源、接口映射、还是前端展示问题
  -> 修改后验证页面和接口一致
```

### 路线 C：发布后页面或接口异常

```text
前端异常 / 接口异常

  -> 看 docker compose 状态
  -> 看 backend / frontend 日志

  -> 确认接口是否走 /api
```
